# BRUTAL

Uma fichinha pra eu jogar com meus amigos. Fica aberto no GitHub caso alguém queira usar também, mas não é um projeto sério — é uma ferramenta caseira que funciona bem pro que a gente precisa.

A **Diretora** cria a mesa, os **Intérpretes** entram com um código e todo mundo vê a iniciativa e as fichas em tempo real pelo celular.

---

## Como usar

### Diretora
1. Cria conta e faz login
2. Cria uma campanha e recebe um **código de sala** (tipo `LAGO-NEGRO-42`)
3. Manda o código pra galera e cai direto no painel da mesa

### Intérpretes
1. Criam conta e fazem login
2. Colam o código em **Entrar como Intérprete**
3. Caem direto na própria ficha

Se sair e voltar, o site te joga de volta pra última mesa automaticamente.

Como é uma coisa entre amigos talvez vocês achem alguns problemas com banco de dados pois uso o meu propio.
